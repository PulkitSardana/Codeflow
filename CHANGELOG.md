# Changelog

All notable changes to CodeFlow are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Improved clone instructions, CI diagnostics, dependency maintenance, and release automation.

## [0.1.0] - 2026-09-26

### Added

- Local Node.js recording with explicit trace spans and stable runtime instrumentation.
- A portable, versioned session format with source locations, HTTP activity, errors, and privacy redaction.
- A local viewer with timeline, call tree, source, HTTP, performance, and comparison views.
- CLI reporting, regression thresholds, browser recording through Playwright, and GitHub Actions coverage.
